# IT Asset Management System — Phase 2: Development

Academic project developed for the **Systems Theory 2** course at the Universidad de San Carlos de Guatemala.

This repository contains Phase 2 of the IT Asset Management (ITAM) system for a university laboratory environment, expanding the prototype built in Phase 1 into a more complete implementation. The project was developed collaboratively as a group assignment.

---

## Overview

Building on the Phase 1 foundation, this phase focuses on the full development of the core ITAM features, refining the frontend interface and backend API established in the previous phase.

---

## Technologies

- **Frontend:** JavaScript, HTML5, CSS3
- **Backend:** Node.js

## Related
